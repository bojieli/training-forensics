### Independent check: the optimizer state of the training run

An earlier revision of the model repository (GAIR/LIMO@1833babb94 global_step234/bf16_zero_pp_rank_{0..31}_mp_rank_00_optim_states.pt (deleted from main in 910230fdaa)) still holds the DeepSpeed optimizer
state of the run. Its fp32 master weights round to the released weights for all 152,064 rows,
and exactly the 29,742 changed token vectors have a nonzero Adam second moment (equal to the changed set: True); every other row equals the base. So the 16,559 changed tokens absent from the published set received real gradients.

- **One run of about the published size.** Adam step 234 on every rank; 32 processes, batch 1, no accumulation, 26 steps per epoch, so 801-832 examples per epoch. The release is the epoch-9 checkpoint of a planned 15-epoch run (lr 5e-06, weight decay 0.0, not resumed). The run size excludes a larger corpus or extra datasets.
- **Questions match, solutions differ.** All 3,437 question tokens changed (0 unchanged). 61 published examples contain solution tokens that never got a gradient (second moment exactly 0, so not a detection floor; 46 of them within the first 4,096 tokens, 76 counting the full text).
- **CJK.** 5,402 of the 25,557 CJK vocabulary tokens changed; the published text contains 46 CJK characters.

**Reading.** The released GAIR/LIMO checkpoint (epoch 9 of a 15-epoch run over about 817 examples) received gradient updates on 16.5k vocabulary tokens, including about 5.4k CJK tokens, that do not occur in the published 817-example set, while about 200 tokens of the published solutions were never updated. The questions match; the solution texts used in training differ from the published ones for at least about 60 examples. The run size excludes a larger corpus. The weights do not show what the other text was or why it differs.

**No implication of test-set training.** Token sets cannot show that an evaluation question was trained on: a question counts as covered below only if every one of its tokens changed, which common tokens make easy. Evaluation questions fully covered by the changed tokens: gaokao 43/79, kaoyan 64/199, grade_school_math 99/210, cn_math_2024 25/30, aime 22/30, math 363/500. These counts are not evidence of contamination and we make no such claim.
