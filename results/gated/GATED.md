Readings:
- **Apertus-v1.5-70B:** base -> SFT -> RL -> release form a clean chain: no weight decay on the token vectors (P = 1) and tens of thousands of bit-identical vectors at every stage. The RL stage leaves the small-update footprint seen in other RL stages (most changed vectors have under half their numbers changed).
- **tiny-aya (Cohere):** one matrix for input and output, so every vector changes; there is no token record.
- **Hydrogen-1.0:** descends from GLM-5.3 as its card says; 103,828 token vectors bit-identical, no weight decay.
- **UserLM-2.0:** descends from Llama-3.1-8B-Instruct, not the base model.
