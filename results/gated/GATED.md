Generated by `scripts/gated/gated_report.py`. With a Hugging Face token the account could authenticate, but every
gated repository below answered 403: access requires accepting each publisher's licence on its model page, which
only the account owner can do. What a token does allow is reading file metadata, including the sha256 of every
weight file. That is enough to check that the open copies we used are byte-identical to the official releases.
