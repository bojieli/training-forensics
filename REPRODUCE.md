# Reproducing the results

Three tiers, from cheapest to most expensive. Every number in `results/**/*.md` comes from a JSON or
JSONL file committed next to it; the tiers differ in whether you regenerate the reports, the JSON,
or the training runs themselves.

## Setup

```bash
pip install -e '.[all]'               # or: pip install -r requirements-lock.txt (exact versions used)
git clone https://github.com/bojieli/checkpoint-forensics ~/checkpoint-forensics   # sibling repo
```

| Variable | Default | Needed for |
|---|---|---|
| `CKPTF_REPO` | `~/checkpoint-forensics` | fingerprint cards and `results/summary.json` of the sibling repo (if absent, the snapshot in `data/ckptf/` is used, so offline rebuilds work from a clean clone): `roster`, `roster-report` (PRETRAIN_DECAY.md), `coverage`, `tokens` pipeline, `frontier_ds` pipeline |
| `TF_CACHE` | the historical `~/.cache/<name>` directories | root of every download cache (embedding tensors, tokenizers, per-token masks, dataset copies) |
| `CKPTF_CACHE` | `$TF_CACHE/trainforensics/emb` | embedding-tensor cache read by `trainforensics.remote` and the sweeps |
| `TF_PINNED=1` | off | fetch the commit pinned in `revisions.json` instead of each repo's `main` |
| `HF_TOKEN` | none | gated repos only (`scripts/gated`; accept each licence on its model page first) |

Results depend on library versions in a few places: the Hugging Face Trainer / accelerate sampler seeding and
scheduler definitions (controlled runs, the s1 seed scan), tokenizer behaviour (published-data audits) and
DeepSpeed's kernels (training stacks). `requirements-lock.txt` pins the versions the results were produced with
(Python 3.10.12, torch 2.10.0+cu128, transformers 4.57.6, accelerate 1.13.0, DeepSpeed 0.20.0).

## Tier 1: offline, from the committed JSON (no network, no GPU, about a minute)

```bash
make test           # 8 unit tests
make all-offline    # regenerates every generated report and prints any file that changed
make figures        # article figures (matplotlib)
```

`make all-offline` was checked in a clean worktree with networking disabled (`unshare -rn`) and empty caches:
every report regenerated byte-identical, except `results/roster/SWEEP.md`, which was stale against
`sweep.jsonl` and was regenerated in the same commit. One target per report:

## Tier 2: re-derive the JSON (network, CPU)

These read embedding tensors with HTTP range requests (no full checkpoint downloads) and cache them under
`TF_CACHE`. Set `TF_PINNED=1` to read exactly the revisions in `revisions.json`.

| Lane | Entry points (in order) | Downloads |
|---|---|---|
| public claims | `make public` | Pythia checkpoint rows, OLMo-2, Qwen2.5 embeddings |
| roster sweep | `make roster` (build_pairs, sweep, report) | ~0.5 TB of embedding tensors for 229 comparisons |
| frontier | scripts/frontier/{special_tokens,qwen3_vision,qwen3_replaced,scout,special_grid,detection_floor}.py, then `make frontier` | roster cache |
| DeepSeek tokens | scripts/frontier_ds/{ds_tokens,ds_shape,ds_tasks,ds_reclass}.py, then `make frontier_ds` | DeepSeek embeddings + checkpoint-forensics V3-Base card |
| frontier_x / y2026_labs / large | scripts/<lane>/{candidates,build,run}.py (y2026_labs: discover first; large: tulu_data, tulu_compare, decay_intervals, kimidev*), then the report target | embeddings of the listed comparisons |
| y2026_ft | scripts/y2026_ft/run.sh, audit_arete*.py, timing.py, then `make y2026_ft` | fine-tune embeddings, Arete data |
| gated | scripts/gated/{mirror_hash,mirror_hash_embed,find405_mirror,cmp405_embed,run_gated,run_gated2}.py, then `make gated` | needs `HF_TOKEN` and accepted licences |
| tokens | scripts/tokens/mine.py, negative_control.py, then `make tokens` | tokenizers + masks from the sweep cache |
| quant_merge | scripts/quant_merge/{quant,gguf_remote,lineage_check,frontier_families}.py; merges: merge_controlled.py (needs mergekit, `MERGEKIT`), real_merges.py | quantized releases' embeddings, GGUF ranges |
| series | scripts/series/{detect,series,analyze,nodecay,bounds,verify}.py, then `make series` | embedding rows of every checkpoint in each series |
| published | scripts/published/{fetch,pfetch,tokens_in_data,lf_exact,compare,cutoff,boundary,change_size,control}.py, then `make published`; WebWorld: ww_fetch, ww_tokens, ww_compare | embeddings + training sets (revisions.json lists them under `dataset:`) |
| LIMO check | scripts/limo_check/* (exact retokenization needs LIMO's vendored LLaMA-Factory on `PYTHONPATH`) | LIMO embeddings, optimizer-state slices from an old revision |
| Arete check | scripts/arete_check/{fetch_emb,a_embed,b_tok,c_format,d_main,e_concat,f_final}.py | Arete + Qwen3.8-27B embeddings, Nous's published data |
| fp32 scan / Reflection | scripts/fp32scan/{scan,headers,s1_forensics,s1_timing,s1_perdoc,pair_forensics,lineage70b*}.py, scripts/reflection_check/* | safetensors headers; s1 and Llama-3/3.1-70B tensors |
| pins | `make revisions` | Hub API only |

`revisions.json` pins 1,717 of 1,725 repos (models and the 15 training sets) to the commit that was `main` on
2026-11-16; results computed earlier read `main` at that time, and `recorded` lists revisions a result file names
explicitly. Eight repos no longer resolve (deleted, renamed or private) and cannot be re-read:
MaziyarPanahi/calme-3-selfmerge-qwen2-78b, MiniMaxAI/Minimax-M3-preview, Qwen/Qwen3.6-35B-A3B-Base,
Umranz/LFM2.5-2.6B-heretic, two huihui-ai gemma-4 abliterated releases, unsloth/llama-3-70b and
unsloth/llama-3-70b-Instruct (the Llama-3 comparisons use other copies verified byte-identical to Meta's by sha256).

## Tier 3: training runs (GPU)

| What | Command | Hardware |
|---|---|---|
| Pythia controlled grid | `make grid score` | one GPU, ~30 min training + scoring |
| gaps runs (swaps, membership, two epochs) | scripts/gaps/runs.sh, runs_fixc.sh, then `make score gaps` | one GPU |
| Qwen2.5-7B controlled runs | scripts/controlled/finetune.py with the settings in results/controlled/q7_*.fp32.json | one 96 GB GPU |
| training stacks | scripts/stacks/grid.sh, q7.sh (DeepSpeed needs `CUDA_HOME`) | one GPU (multi-rank runs emulated on one GPU) |

Training outputs go to `runs/` (not committed); `make score` loops over the run directories that exist.

## What cannot be reproduced from this repo alone

- Inputs deleted after use: the embedding caches (about 0.5 TB), the Qwen2.5-7B controlled-run weights from the
  first round (since retrained), and downloaded datasets. Tier 2 re-downloads them; repos that no longer resolve
  are listed above.
- Some report scripts still contain numbers typed in from earlier analyses rather than read from JSON; see
  `FIXLOG/fixD.md` for the list.
